# Data Analysis: Film Performance and Audience Engagement Analysis

## Overview

This repository contains a coding sample focused on analyzing film performance, audience engagement, churn risk, and film success prediction using SQL and Python.

The project demonstrates an end-to-end data analysis workflow, including data loading, cleaning, SQL-based aggregation, descriptive analysis, feature engineering, predictive modeling, model evaluation, and business interpretation. The analysis is organized in a Jupyter notebook with comments and markdown explanations throughout.

This sample was prepared as a data ETL and analysis coding sample for a Data Analyst role. It is intended to show practical experience working with structured datasets, querying data, building reproducible Python workflows, and translating technical results into clear findings for non-technical stakeholders.  
<br>

## Project Objectives

The analysis addresses three main areas:

1. Audience engagement and churn risk  
2. Film performance and ROI analysis  
3. Open-ended business and investigative questions  

The project uses SQL for aggregation and exploratory queries, and Python for data preparation, modeling, evaluation, and interpretation.  
<br>

## Datasets

The project uses three CSV files:

| File | Description |
|---|---|
| `film_performance.csv` | Film-level performance information, including views, costs, revenue, and related metrics |
| `film_metadata.csv` | Metadata for a subset of 20 films, including film length and genre |
| `user_activity_with_cost.csv` | User-level film viewing events, including watch activity and ticket cost |

The files are placed in the `data/` folder.
